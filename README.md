## Commit Convention

| 커밋 필드 | 설명 |
|----------|------|
| Feat     | 새로운 기능 추가 및 수정 |
| Fix      | 버그 수정 |
| Chore    | 빌드 설정, 폴더 구조, 프로젝트 세팅 등 |
| Refactor | 기능 변화 없는 코드 개선 |
| Add      | 문서, 에셋, 설정 등 추가 |
| Remove   | 코드/파일/에셋 삭제 |
| Bug      | 불가피한 오류 상태 공유 시 명시 |
| Design   | 디자인 변경 (아트 전용) |
